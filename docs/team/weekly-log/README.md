# Weekly contribution log

One file per ISO week, `YYYY-Www.md`, with a section for each of us.

Each file has two kinds of content:

- **From git** — commits and files touched that week, refreshed automatically.
- **In our own words** — a short paragraph on what was done and what it moved, added with
  `/weekly-log`. This is where work that git cannot see belongs: a stakeholder meeting, writing
  articles, preparing the demo, reading up on something before deciding.

The course asks for this at every stage (course requirements, section 10.5). It is also the earliest
place a problem shows up: a week with nothing in it from one of us is visible immediately rather
than in October.

Write the paragraph in the week it happened. Reconstructed logs read as reconstructed.
