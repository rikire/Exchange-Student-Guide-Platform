Buttons and page width

One set of buttons for every page, so an action reads as an action (walkthrough fix 3.2), and a wider page frame (3.1).

The page frame

Running text keeps a readable measure of about 70 characters, however wide the window. The frame grows to 1440 px (it was 1100), so at 1920 px it is 75 % of the window instead of 57 %; what fills the extra width is what sits beside the text — the article's and the landing page's sidebar (3.4, 3.5), the wide editor (3.6), the queue and the review page at full width.
