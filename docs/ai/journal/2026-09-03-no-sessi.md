PHASE 0 - WHAT WAS ACTUALLY DONE.

Delivered: Maven wrapper (neither Maven nor make was installed); multi-module build; ai-tools.jar with hook prompt/guard/stop/note/english and commit-msg; CLAUDE.md and eleven documents in docs/ai/; docs/repository-map.md; the documentation skeleton across fourteen directories; docs/course/rubric.md; eleven slash commands; git hooks; CI; scripts/check.sh and scripts/hooks.sh. 103 files, 25 tests.

Verified rather than assumed: a clean build on Temurin 21; the commit-message gate rejecting a non-conforming message with exit 1; the guard hook asking on docs/requirements and staying silent on ordinary source; the journal writing a non-empty entry; and detection of edits made by hand between turns, tested with both a modified and a deleted file.

Deviations from the plan, each with its reason:
- Java 17 to 21. The plan chose 17 only because it was installed. Temurin 21 was installed later in phase 0 and made the default, which also removed a GraalVM-versus-Temurin mismatch against CI.
- The tools module stayed on release 17 while the application moved to 21, because the hooks invoke it as plain java -jar under whatever JDK is first on PATH.
- Makefile replaced by scripts/*.sh: make is not installed, and a wrapper nobody can run is worse than none.
- Maven deliberately not installed: the wrapper pins 3.9.16, and a system-wide Maven would be a second way to build.
- Spring Boot 3.5.16 rather than 4.1.1, because Boot 4 pulls Hibernate ORM 7.4 and Modulith 2.x, a combination with little settled documentation - and both of us must explain every line at the viva.

Problems found and recorded rather than smoothed over:
- DEBT-001: a journal translation binds to a session rather than to a specific entry, so a rendering supplied with no entry open attaches to the next one. Observed during this phase.
- VS Code user settings were injecting JDK 17 into the integrated terminal, which would have made every terminal build fail against release 21. Fixed with a committed workspace settings file containing no machine-specific paths.
- Earlier scripted edits wrote CRLF line endings; Spotless caught it and four files were repaired.

Not done, and blocking nothing yet: Abdirakhim's git email in docs/team/members.yml, without which contribution attribution falls through to unknown; and the first seed articles.
