**Date:** YYYY-MM-DD

## Context

What forced this decision. Name the constraint that actually binds — a deadline, a dependency, the
size of the team, something the stakeholder said. Context that would be true of any project is not
context.

## Options

### A. Name

What it is. What it costs. What it makes easy and what it makes hard.

### B. Name

The same. **An ADR with one option is a rationalisation, not a decision** — if the alternative was
never genuinely considered, say that instead of inventing one.

## Decision

Which option, and the one thing that decided it.

## Consequences

**Good:** what becomes easier.

**Bad:** what becomes harder, and what we are now committed to. This section being empty means the
analysis is not finished.

**Reversal:** what it would cost to undo this later, and what would trigger reconsidering it.
