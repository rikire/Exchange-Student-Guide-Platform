There are two separate document checklists in this process, and they are not identical. Mixing them
up is the easiest way to have an upload rejected, so this article keeps them apart deliberately.

## IIT Madras's own document set (from the OGE brochure)

Split into two groups with different size limits:

**PDF documents — max 1.5 MB each:**
- Home Institute ID Card
- Curriculum Vitae (CV)
- English Proficiency Certificate
- Nomination Letter from Current Institute
- Latest Transcript

**Image documents — max 2 MB each, JPG/JPEG/PNG:**
- Student Signature
- Student Photo (for ID card purposes)

## SII portal's document set (from the Study in India dashboard)

On the SII dashboard specifically, during [[Filling in Your SII Student Dashboard]]:
- Passport / national ID proof — PDF/JPG/PNG, max 2 MB
- Medical fitness certificate — PDF/JPG/PNG, max 2 MB
- Academic transcripts/marksheets per qualification level — PDF only, max 2 MB

## Where these differ

Notice the PDF limit is **1.5 MB** on IIT Madras's own set and **2 MB** on the SII portal's set. This
guide does not assume that's a typo — it's recorded as-is from two separate official sources, and
you should check with OGE which limit applies to which upload if you're ever unsure which system
you're uploading into.

## Practical advice

Compress scans before you start — a phone-camera photo of a passport page easily exceeds 2 MB
unedited. Keep both a full-resolution original and a compressed copy, since you may need the same
document for both checklists above.

## Needs checking with OGE before this goes in front of students

- Whether the two document sets above are genuinely separate submissions, or whether IIT Madras's own
  set is simply a pre-check before the same files go into the SII portal.
