Starter articles, written directly in the format the importer reads: Markdown with YAML front
matter. One mechanism serves seeding, backup, transfer between stands and test fixtures.

The seed is test and demonstration data, not the production guide (the human, 1 Oct). Its `views`
counts are made up, so that a fresh stand has an order to show under "Most viewed" (FR-033); a real
stand's counts come from readers.

Start a draft with `/article <topic>`. See docs/roadmap/00-init.md for what is expected here.
